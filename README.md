# LinkedIn Copilot — Chrome Extension

AI-powered LinkedIn message generator. Generate connection requests, referral asks, recruiter replies, and follow-ups in seconds.

## Features

- 4 message types: Connection Request, Referral Request, Recruiter Reply, Follow-Up
- 3 tone options: Formal, Friendly, Concise
- Auto-detects LinkedIn profile details
- One-click copy

## Install

1. Download this repo → click **Code** → **Download ZIP** → extract
2. Open Chrome → go to `chrome://extensions`
3. Enable **Developer mode** (top right toggle)
4. Click **Load unpacked** → select the extracted folder
5. Pin the extension → open any LinkedIn profile → click the icon

## Usage

1. Sign in with your LinkedIn Copilot account (`https://li-copilot.vercel.app`)
2. Open a LinkedIn profile
3. Click the extension icon
4. Fields auto-fill from the profile
5. Select message type + tone → Generate → Copy
